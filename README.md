# AI 模拟炒股盘（10 万本金 · 真实行情 · 本地撮合）

一个用**真实 A 股行情**驱动、**我（AI）自己决策**的模拟交易账户。每次操作都留痕：为什么买、为什么卖、成交价怎么算、费用多少，都能在网页上看。

网页看板：**http://127.0.0.1:8787**

---

## 快速上手

```powershell
cd C:\Users\23077\Desktop\work_place\ai_money

node src/init.js     # 初始化账户（全市场扫描 + 建仓），只在第一次或重置时用
node src/server.js   # 网页看板（后台常驻）
node src/loop.js     # 心跳进程：交易时段每 3 分钟、非交易时段每小时跑一次
node src/tick.js --force   # 手动跑一次心跳（盘中会执行待办、生成新计划）
node test/unit.js          # 账务与信号规则单测（20 项）
node test/e2e-execute.js   # 端到端：待办 -> 开盘成交（9 项）
```

> 重置账户：删掉 `data/state.json` 和 `data/last-scan.json`，再跑 `node src/init.js`。

## 交易规则（会被严格执行）

见 `src/lib/strategy-config.js`，并在网页"策略规则"区原样展示。核心：

- **选股**：全市场 5500+ 只 → 硬筛（非 ST/北交所、流通市值 50–5000 亿、20 日均成交额 ≥ 8000 万、一手 ≤ 1.6 万）→ 前复权日K 打分
- **打分**：`0.5×20日涨幅 + 0.3×60日涨幅 − 0.2×20日波动率`；大盘跌破 MA20 时分数 ×0.5
- **持仓**：最多 5 只，单只目标 18%，弱势市场初始仓位上限 60%
- **卖出**：成本 −8% 止损；盈利中从最高收盘回撤 12% 止盈；动能排名跌出前 10 换仓
- **执行**：收盘后生成计划，**下一交易日开盘价**成交（含 0.1% 滑点），不存在当日买卖同一标的
- **费用**：佣金 0.025%（最低 5 元）+ 卖出印花税 0.05%

## 数据来源与已知局限

| 用途 | 来源 |
|---|---|
| 全市场列表 | 新浪 `Market_Center`（100 条/页 × 56 页） |
| 前复权日K | ① 东财 `fqt=1`（走 curl，Node 直连被 TLS 指纹拦）→ ② 新浪原始价 + 新浪复权因子本地复权 → ③ 新浪原始价 |
| 实时报价 | 腾讯 `qt.gtimg.cn`（GBK） |
| 指数 | 腾讯日K |

**本地复权公式**（已用东财前复权数据交叉验证，160 天平均偏差 0.045%~0.23%）：

```
前复权价 = 原始价 × Π ( f[下一个除权日] / f[该除权日] )，对所有 除权日 > 该K线日期
```

**必须知道的局限**（复盘时请据此打折）：

1. **前视偏差 / 幸存者偏差**：股票池取自"当前还在交易"的股票，已退市的强势股不在池里，长期回看会略微高估策略。
2. **成交价理想化**：按开盘价成交。一字涨停买不进的情况已过滤，但盘中流动性冲击、涨跌停封板无法完整模拟。
3. **没有分红现金**：日K 是前复权的，价格收益正确，但累计净值不含现金分红的再投资收益。
4. **只用了价量**：没有财报/公告/资金面/龙虎榜数据，策略纯粹是动量。
5. **样本期短**：从 2026-10-16 起，只有实盘向前推进，不存在回测曲线。
6. **策略本身激进**：选出来的多是 20/60 日翻倍的妖股，波动率 30%+，回撤会很难看。这是有意的——要看输赢就看得明显一点。

## 历史回放（`src/replay/`）——不等开盘，立刻看过程

把真实历史行情倒带重炒，**严格无未来函数**：决策只用截至当天的数据，成交用**次日开盘价**，T+1、费用、-8% 止损、-12% 移动止盈、排名跌出前 10 换仓全部照常执行。

```powershell
node src/replay/cache.js                        # 缓存 600 只标的 + 指数历史日K（约 92MB）
node src/replay/export-contexts.js 2026-07-01   # 导出逐日看盘上下文（含无未来函数的候选排名）
node src/replay/run.js context 2026-08-05       # 单日看盘
node src/replay/run.js run <计划文件> 2026-07-01  # 按计划执行，产出账户与报告
node src/replay/run.js baseline 2026-07-01      # 机械规则基线
node src/replay/benchmarks.js                   # 各对照策略对比
node src/replay/report.js                       # 渲染 data/replay/report.html 复盘页
```

### 2026-07-01 ~ 2026-10-16（72 个交易日）实测结果

| 策略 | 期末总资产 | 收益率 | 最大回撤 | 成交 | 卖出胜率 |
|---|---|---|---|---|---|
| **AI 操盘手（子代理，72 天只出手 1 次）** | **99,572.38** | **-0.43%** | **-3.66%** | 6 | 33% |
| 完全空仓（什么都不做） | 100,000.00 | 0.00% | 0.00% | 0 | — |
| 上证指数本身 | 90,366.57 | -9.63% | -9.85% | 0 | — |
| 机械规则 + 趋势过滤 + 每日最多 1 只 | 84,023.86 | -15.98% | -21.98% | 32 | — |
| 机械规则 + 趋势过滤（MA20 闸门） | 80,210.02 | -19.79% | -25.39% | 54 | 33% |
| **机械规则（实盘那套，无过滤）** | **77,505.25** | **-22.49%** | **-26.46%** | 89 | 28% |
| 期初等权买入动能前 5 并持有不动 | 46,640.35 | -53.36% | — | 0 | — |

**结论（这段行情）**：机械执行必然亏钱，亏损源不是选股而是「每天都必须买」——MA20 开关只把分数 ×0.5、敞口压到 60%，并不阻止它在下降趋势里反复接飞刀。人的边际价值几乎全部来自**什么时候不玩**。注意这段行情的特殊性：大盘跌 9.6%、动能前 5 名腰斩，「不玩」天然占优；换成单边上涨行情，同一条空仓规则会大幅跑输。**这是样本内的一次演示，不是可外推的 alpha。**

## 和什么比？

页面上的"对比基准"= **初始化时同样这几只、等权买入后一路持有不动**（不做止损、不做换仓）。只有跑赢这个基准，才说明止损/换仓这些操作创造了价值；否则不如躺平。

## 运维

- 心跳进程与网页服务都是常驻 node 进程。日志直接看进程输出。
- 同一时间只有一个进程能写状态（`data/*.lock`），重复启动会等待或跳过。
- 想手动干预：直接编辑 `data/state.json` 的 `pending` 数组，下一交易日开盘会按你的指令成交。
